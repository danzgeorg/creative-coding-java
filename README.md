# Creative coding (Processing)

Sketches from my first-year creative coding module, written in [Processing](https://processing.org) (a Java-based language for graphics).

| Sketch | What it is |
|---|---|
| `pathfinder_game` | A small game |
| `circle_hunt` | A click-the-target game |
| `simple_nature_scene` | A drawn landscape |
| `london_underground_logo` | The Underground roundel drawn with shapes |
| `bouncing_ball`, `travelling_circles` | Animation and movement |
| `rgb_selector` | Interactive colour picker |
| `digital_timer` | A running clock |
| `heads_or_tails`, `TwoCoins` | Random coin flips |
| `message_wrap_around`, `variable_arithmetic` | Text and variables |

To run one, install Processing, open the `.pde` file and press **Run**.
